PURITY RITUAL PROFESSIONAL BASELINE V1

فك الضغط ثم افتح PowerShell داخل المجلد وشغّل:
npm install
npm run dev

افتح الرابط المحلي الذي يظهر في PowerShell.

النسخة الحالية للاعتماد البصري وتشمل:
- لوحة إدارة احترافية ومتجاوبة.
- معاينة بوابة العميل.
- هوية Purity Ritual الجديدة.
- صور احترافية أصلية بشعار الشركة.
- أقسام الطلبات والعملاء والعروض والعقود والفواتير والتحصيل.

قاعدة البيانات:
- احتفظ بمشروع Supabase الحالي.
- ملفات SQL السابقة موجودة داخل مجلد supabase.

مهم:
- هذه نسخة اعتماد الواجهة الجديدة قبل ربط جميع الشاشات بعمليات Supabase.
- لا ترفعها إلى GitHub أو Cloudflare قبل الاعتماد النهائي.
