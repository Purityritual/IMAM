Purity Ritual V1.9 — Public Website + Guest Quote
==================================================

- الموقع والخدمات وبيانات التواصل متاحة للزائر دون تسجيل.
- طلب عرض سعر بدون إنشاء حساب.
- لا يستطيع الزائر قراءة أي طلبات؛ مسموح له الإرسال فقط.
- العملاء المسجلون يدخلون لبوابة العميل.
- الموظفون يدخلون للوحة الإدارة حسب دور الحساب.

أولًا: نفّذ supabase/004_PUBLIC_QUOTE_REQUESTS.sql في Supabase SQL Editor.

ثم فك الملفات فوق المشروع وشغّل:
cd C:\projects\PurityRitual\repo
npm install
npm run build
npm run dev

الاختبار:
1. افتح الموقع بدون تسجيل وتصفح الخدمات.
2. اضغط طلب عرض سعر مجانًا وأرسل طلبًا.
3. تأكد من ظهور السجل في pr_public_quote_requests.
4. اختبر دخول عميل ودخول موظف كلٌ بحسابه.
